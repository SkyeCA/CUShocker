CUShocker {VERSION}

Shocks your OpenShock shockers when you get hurt in Casualties Unknown.

Needs BepInEx 5 and OpenShock Desktop {DESKTOP_VERSION} or newer.


Install

1. Copy the BepInEx folder from "Casualties Unknown" into your game folder (where CasualtiesUnknown.exe is).

2. Close OpenShock Desktop, then copy the modules folder from "OpenShock Desktop" into %APPDATA%\OpenShock\Desktop
   (paste that path into the Explorer address bar).

3. Start OpenShock Desktop and open CUShocker in the sidebar. Pick your shockers and set the intensity.
   It starts in Test mode, which shows what it would send without sending anything. Switch to Live when you're happy with it.


Uninstall

Delete BepInEx\plugins\CUShocker in the game folder and %APPDATA%\OpenShock\Desktop\modules\my.vore.cushocker
