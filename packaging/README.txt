CUShocker {VERSION}

Requirements

- Casualties Unknown with BepInEx 5 installed
- OpenShock Desktop 1.3.1+ if using OpenShock
- MultiShock 4.8.3+ if using PiShock

Install

1. Copy the BepInEx folder from "Casualties Unknown" into your game folder (where CasualtiesUnknown.exe is).

2. Install the module for the app you use:

   OpenShock: Close OpenShock Desktop if it's open, then copy the modules folder from "OpenShock Desktop" into %APPDATA%\OpenShock\Desktop
   Start OpenShock Desktop and open CUShocker from the sidebar.

   PiShock: Close MultiShock if it's open, then copy the Plugins folder from "MultiShock" into %LOCALAPPDATA%\PiShock\MultiShock
   Start MultiShock, open Plugin Settings, expand CUShocker and set its sidebar page to Shown, then open CUShocker from the sidebar.

3. Pick your shockers and change the settings to your liking.
   * The first run will start in 'Test Mode' so switch to 'Live' when you're ready to be shocked!
   * Only run one of the two modules at a time! You can't use OpenShock and MultiShock at the same time with this mod!


Uninstall

Delete BepInEx\plugins\CUShocker in the game folder, then delete %APPDATA%\OpenShock\Desktop\modules\my.vore.cushocker
or %LOCALAPPDATA%\PiShock\MultiShock\Plugins\my.vore.cushocker
