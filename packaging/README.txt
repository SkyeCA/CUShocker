CUShocker {VERSION}

Needs BepInEx 5 and OpenShock Desktop {DESKTOP_VERSION} or newer.

Install

1. Copy the BepInEx folder from "Casualties Unknown" into your game folder (where CasualtiesUnknown.exe is).

2. Close OpenShock Desktop if it's open, then copy the modules folder from "OpenShock Desktop" into %APPDATA%\OpenShock\Desktop
   (paste that path into the Explorer address bar).

3. Start OpenShock Desktop and open CUShocker in the sidebar. Pick your shockers and change the settings to your liking.
   * The first run will start in 'Test Mode' so switch to 'Live' when you're ready to be shocked!


Uninstall

Delete BepInEx\plugins\CUShocker in the game folder and %APPDATA%\OpenShock\Desktop\modules\my.vore.cushocker
